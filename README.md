# Meu_app

Atividade de Versionamento com Git e GitHub
📚 Sobre a atividade

Este projeto foi desenvolvido como parte das atividades da disciplina, com o objetivo de praticar o uso do Git e GitHub para controle de versões de um projeto em Python.

Durante as aulas, diferentes versões do código eram armazenadas em arquivos separados. Nesta atividade, o objetivo é aplicar os conceitos de versionamento de código, mantendo todas as alterações em um único arquivo Python e utilizando os commits do Git para registrar a evolução do projeto.

🎯 Objetivos

Criar e utilizar uma conta no GitHub.

Organizar o código Python em um único arquivo.

Utilizar o Git para controlar as diferentes versões do código.

Criar commits para registrar cada alteração realizada.

Enviar as alterações para um repositório remoto no GitHub.

Trabalhar com branches para representar versões específicas do projeto.

Praticar o fluxo de trabalho com stage, commit e push.

🛠️ Tecnologias utilizadas

Python

Git

GitHub

📁 Organização do projeto

O código Python é mantido em um único arquivo, evitando a criação de arquivos diferentes para cada versão.

A evolução do código é registrada por meio dos commits realizados no GitHub. Dessa forma, cada commit representa uma versão ou etapa do desenvolvimento do projeto.

A pasta template também é utilizada para a organização das versões relacionadas às aulas.

🔄 Versionamento

Para cada versão do código, foi realizado o seguinte processo:

Alteração do código Python.

Adição dos arquivos ao staging area do Git.

Criação de um commit descrevendo as alterações realizadas.

Envio (push) das alterações para o repositório no GitHub.

Repetição do processo para cada nova versão.

O projeto possui no mínimo quatro commits, representando diferentes etapas da evolução do código.

🌿 Branch para versão específica

Foi criado um branch específico para representar a versão do código que utiliza o conceito de herança de template, trabalhado na Aula 6.

Para a versão da Aula 7, que originalmente utilizava uma pasta diferente (t_template), foi dada continuidade à organização utilizando a pasta template.

👨‍💻 Conclusão

A atividade permitiu compreender, na prática, como o Git e o GitHub podem ser utilizados para acompanhar a evolução de um projeto. Em vez de manter diversos arquivos para representar cada versão do código, as alterações são registradas por meio de commits, facilitando o acompanhamento, a organização e a recuperação de versões anteriores do projeto.
